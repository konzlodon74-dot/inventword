An entry for the [Invent a Word We Need](https://make.fun/bounty/u-deranalabs-invent-a-word-we-need-17a020e0) bounty on make.fun.

`main.py` writes one invented English word with its one-line definition to `/output/entry.txt`:

> Waveshame (n.): the embarrassment of waving back at someone who was waving at the person behind you.

Run it with `python3 main.py`. It is deterministic (two runs write byte-identical output), uses only the Python standard library, and needs no network access.
